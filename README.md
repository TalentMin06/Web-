# 灵魂底色 · Color Within

适合手机使用的静态 H5 自我探索测试，无登录、无付款、无后端、无外部运行依赖。

## 本地运行

在现有检出目录 `/workspace/Web-` 运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

访问根路径即可开始。12 道题生成苔绿、蜜桃、鸢紫或雾蓝结果，包含完整解读与 900 × 1450 PNG 结果卡。手机可长按结果图片保存，也可以点击下载。结果根据四类选项计数；同分时依次采用苔绿、蜜桃、鸢紫、雾蓝。仅供娱乐与自我探索，不是经过专业验证的心理量表。

## 发布

将 `index.html` 上传到任意支持 HTTPS 的静态托管即可；无需构建，无需环境变量。当前尚未发布。

如果使用 GitHub Pages，将文件提交至仓库后，在仓库 Settings → Pages 选择对应分支与根目录；实际可用地址以 Pages 发布成功提示为准。

## 验证

已经使用 Chromium 的 390 × 844 手机视口验证完整答题、返回修改、重新测试、结果卡图片生成与页面无横向溢出。尚未在真实 iOS / Android 设备和小红书内置浏览器验证保存操作。
